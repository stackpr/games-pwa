How to play

  • Build words from the seven letters. The gold letter in the middle has to be in every word.
  • Letters can be used as many times as you like.
  • Words are four letters or longer.
  • No plurals ending in s — there is never an s in the hive.
  • Every hive has at least two vowels, so there is always something to build on.
  • Type on a keyboard if you have one: letters, Backspace, Enter. Space shuffles.

Scoring

Each letterits value, shown on the tile
Length1, 4, 9, 16, 25… per letter past four
All seven lettersplus 10 — a pangram

Letter values are the familiar ones — e and a are worth 1, k is 5, q and z are 10. So a short word made of awkward letters can beat a longer easy one, while length wins outright once a word gets really long.

The clock

  • Pick a limit before you start. A short game is a different game, so each limit keeps its own top five.
  • A game cannot be paused or resumed: reloading the page ends it.

The seven letters are drawn fresh every game. A guess is checked first against the site’s own small vocabulary and then, if that does not know it, in a real dictionary — so the whole language is in play, and, unlike everything else here, this game needs a connection. If the dictionary does not answer, the word waits in the strip below the hive and is asked about again; a word that is never answered costs you nothing.

Lookups use dictionaryapi.dev and FreeDictionaryAPI.com, which draws on Wiktionary. Two of them, so one being down is not the same as the dictionary being down.
